Comment configurer Azure ?
  1. Aller sur portal.azure.com
  2. Azure Active Directory → Inscriptions d'applications
  3. Nouvelle inscription → nom : "Remontées Support"
  4. Type de compte : "Comptes dans cet annuaire uniquement"
  5. URI de redirection : {{ redirect_uri }}
  6. Copier le Client ID et Tenant ID
  7. Certificats et secrets → Nouveau secret client → copier la Valeur
  8. API autorisées → Ajouter : Mail.Read Mail.ReadWrite Mail.Send
Permissions requises :
Mail.Read · Mail.ReadWrite · Mail.Send · User.Read · offline_access
